Sheet layout: five 32 x 32 cells per row with a 1 px gutter, grey background,
the author's signature under row 3. Cell origins (x, y):
  row 0 (y 7):  5, 38, 71, 104, 137  — bearded warrior, bald man, headband rogue,
                                        circlet woman, orc
  row 1 (y 40): 5, 38, 71, 104, 137  — old wizard, skull, stone brute,
                                        red-haired woman, visored knight
  row 2 (y 73): 5, 38 (y 72), 71      — grey-haired woman, hooded helm, bearded dwarf
  row 2 cell 4 (104, 73) is the author's "?" placeholder and is never shown.

Usage in RTS Agents: client/src/utils/portraits.ts maps each hero's LPC look
to a few fitting faces and draws one cell as a CSS sprite (party cards,
terminal tabs, journal and toast chips). The file is used unmodified.
