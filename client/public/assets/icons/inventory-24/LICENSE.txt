Usage in RTS Agents: components/PixelIcon.tsx (BagIcon) draws the bag cell as a CSS
sprite for the top-bar backpack button and the Backpack panel header / tab. The
"open" state is a CSS transform on the flap region of the same cell, not a second
image. The file is used unmodified.
